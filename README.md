# TCG코리아 (프로토타입)

포켓몬 카드 거래 플랫폼 프로토타입입니다. 단일 HTML 파일로 동작하며 외부 요청이 없습니다.

- 데모: https://pispherelab-admin.github.io/tcg-korea/
- 화면: 홈 / 마켓 / 상품 상세 / 시세표 / 내 도감 / 판매 등록 / 장바구니 / 마이페이지

## 판본별 시세

한글판 · 일본판 · 북미판을 각각 다른 출처에서 실측해 원화로 나란히 비교합니다.
**추정 시세는 만들지 않고, 확인되지 않은 판본은 표시하지 않습니다.**

| 판본 | 출처 | 가격의 의미 |
|---|---|---|
| 일본판 | SNKRDUNK 마켓 리포트 + 상품 페이지 | 현재 최저 판매가 (¥) |
| 북미판 | pokemontcg.io가 제공하는 TCGplayer 마켓 시세 | 최근 체결 기반 마켓 시세 ($) |
| 한글판 | 중고나라 공개 검색 | 한글판 낱장 **호가**의 중앙값 (₩) |

한글판은 체결가가 아니라 호가이며, 일본판·영문판·감정품·묶음 매물을 제외하고
표본 2건 이상 + 사분위 산포 4배 이내인 카드만 산출했습니다. 표본 수를 화면에 함께 표시합니다.

카드명·카드번호·레어도·세트·이미지는 SNKRDUNK 표기 원문을 파싱한 값이며,
포켓몬 한국 정식 명칭을 확실한 것만 병기했습니다(모르는 이름은 번역하지 않고 원문 유지).

## 사용하지 않은 출처

robots.txt에서 크롤러를 차단한 사이트는 사용하지 않았습니다.

- **ICU(너정다)** — `User-agent: ClaudeBot / anthropic-ai / Claude-Web → Disallow: /`
- **번개장터** — 동일하게 Claude 계열 크롤러 차단
- **카드냥** — `Disallow: /`
- **카드매니아** — 봇 정책 목록에 ClaudeBot 포함
- **eBay** — robots.txt에서 자동 접근을 명시적으로 금지 (공식 API 별도 필요)
- **SNKRDUNK 내부 API** (`/en/v1/*`) — robots.txt Disallow
