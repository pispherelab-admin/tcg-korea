# TCG코리아 (프로토타입)

**개인 간(C2C) 포켓몬 카드 거래 플랫폼**입니다. 메루카리 모델을 참고했고,
플랫폼은 거래가 성사될 때 **판매 수수료 10%**로 수익을 냅니다.
단일 HTML 파일로 동작하며 외부 요청이 없습니다.

- 데모: https://pispherelab-admin.github.io/tcg-korea/
- 화면: 홈(피드) / 매물 찾기 / 매물 상세 / 팔기(출품) / 내 거래 / 마이페이지 / 수수료 정책 / 시세표

## 수익 모델

| 항목 | 요율 | 비고 |
|---|---|---|
| 판매 수수료 | **10%** | 거래 완료 시에만 부과 (부가세 포함) |
| 구매 수수료 | 0원 | 구매자는 판매가 + 배송비만 |
| 출품 수수료 | 0원 | 등록·보관·유지 비용 없음 |
| 출금 수수료 | 300원/건 | 잔액으로 재구매 시 무료 |

메루카리와 같은 10%를 유지하면서 구매자 수수료를 없앴습니다.
국내 오픈마켓(약 13%) 대비 판매자가 3%p 더 가져갑니다.

`수수료 정책` 화면에 판매가를 바꿔가며 확인하는 계산기와, 이 프로토타입 거래 데이터 기준의
GMV·수수료 수익·건당 평균 거래액을 함께 넣었습니다.

## 거래 흐름

출품 → 구매자 결제(대금은 플랫폼이 보관) → 안심배송 발송 → 수령 확인 → 판매자 정산.
`내 거래` 화면에서 5단계 상태를 직접 진행해 볼 수 있습니다. 안심배송은 서로의 주소를 노출하지 않습니다.

## 시세 데이터 — 출품 가격 결정 도우미

한글판 · 일본판 · 북미판을 각각 다른 출처에서 실측했습니다.
**추정 시세는 만들지 않고, 확인되지 않은 판본은 표시하지 않습니다.**

| 판본 | 출처 | 가격의 의미 |
|---|---|---|
| 일본판 | SNKRDUNK 마켓 리포트 + 상품 페이지 | 현재 최저 판매가 (¥) |
| 북미판 | pokemontcg.io가 제공하는 TCGplayer 마켓 시세 | 최근 체결 기반 마켓 시세 ($) |
| 한글판 | 중고나라 공개 검색 | 한글판 낱장 **호가**의 중앙값 (₩) |

모든 매물에 "시세 대비 −N%"가 표시되고, 출품 화면에서는 시세 기준 가격 제안과
같은 카드의 다른 판매자 가격을 함께 보여줍니다.

## 사용하지 않은 출처

robots.txt에서 크롤러를 차단한 사이트는 사용하지 않았습니다.

- **ICU(너정다)** — `User-agent: ClaudeBot / anthropic-ai / Claude-Web → Disallow: /`
- **번개장터** — 동일하게 Claude 계열 크롤러 차단
- **카드냥** — `Disallow: /`
- **카드매니아** — 봇 정책 목록에 ClaudeBot 포함
- **eBay** — robots.txt에서 자동 접근을 명시적으로 금지 (공식 API 별도 필요)
- **SNKRDUNK 내부 API** (`/en/v1/*`) — robots.txt Disallow
